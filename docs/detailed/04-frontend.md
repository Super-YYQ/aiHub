# 04 前端

视觉与动效的数值见 [08-ui-spec](08-ui-spec.md)；接口见 [03-api](03-api.md)。原型 `prototype/` 是交互的参考实现，页面结构、文案和交互细节以原型为准，除非本文另有说明。

五种界面结构都要实现。下面的页面规格按结构 1（三栏）编写；其他结构的“工作台”和“条目”两类页面按 [08-ui-spec](08-ui-spec.md#界面结构) 实现，其余页面各结构共用。路由与结构无关：同一个网址在任何结构下都打开同一个页面或条目。

## 路由

使用 history 模式，Worker 对未知路径返回 `index.html`。

| 路径 | 页面 | 说明 |
| --- | --- | --- |
| `/` | 工作台 | |
| `/list/:scope/:id?` | 条目 | `scope` 是 `all`、`inbox`、`pinned`、某个状态或某个类型 ID |
| `/new/:type?` | 新建条目 | 可带 `?title=` 预填名称 |
| `/edit/:id` | 编辑条目 | |
| `/stacks`、`/stacks/new`、`/stacks/:id`、`/stacks/:id/edit` | 环境列表、新建、详情、编辑 | |
| `/proposals` | 待确认 | 可带 `?scanRun=` 只看某次扫描 |
| `/settings`、`/settings/types`、`/settings/platforms`、`/settings/tags` | 数据与设置、字典管理 | |

## 页面规格

**工作台**
- 顶部是快速记录框：类型选择、输入框、“存入待整理”按钮，回车提交（手机上改用记录面板，见下文）。
- 下面依次是：置顶、最近更新（不含置顶，最多 6 条）、在用构成（按类型的分段条和图例）、待整理、待确认（有提案时显示数量和入口）、试用中与想试。
- 档案为空时显示首次使用引导，给三个入口：导入原型数据、运行本机扫描器、新建第一条。

**条目（列表 + 详情）**
- 桌面端左列表右详情；手机端列表和详情分两屏，详情页左上角有返回按钮。
- 筛选栏固定在列表顶部：状态（范围本身是状态时不显示）、平台、标签、排序（最近更新、名称、评分）。筛选按范围分别记忆，有筛选生效时显示“清除筛选”。
- 桌面端在同一列表里切换条目时，列表保持挂载、滚动位置不变，只替换详情。
- 列表获得焦点时，上下方向键移动选中项，回车打开。

**详情**
- 头部：类型标记、路径 `类型/标识`、状态下拉、置顶、复制为 Markdown、编辑，以及“更多”菜单（历史版本、删除）。
- 正文依次是：名称、一句话说明、平台/标签/环境标签、待整理提示、片段、要点、笔记、链接、记录（创建和更新时间、版本号、“查看历史”）。
- 片段：复制按钮；含变量时显示变量输入框，按钮文字变为“填好后复制”，未填的变量保留原样；安装命令有“安装命令”标记。
- 历史版本从右侧抽屉打开：列出修订，选中后与当前版本逐字段对比，笔记和片段按行对比，可“恢复此版本”。

**新建与编辑**
- 字段与原型一致；类型的字段模板作为要点的占位提示，并提供可点击的建议键。
- 片段可新增、删除、上下移动。
- 有未保存修改时离开页面要确认；`Ctrl+S` 保存。
- 服务端返回的校验错误和密钥扫描结果显示在对应字段下方。

**环境**
- 环境列表、详情、编辑与原型一致：详情页有“编辑环境”“添加条目”“生成安装清单”；物料清单每行可移出，并可就地编辑“本环境下的备注”。
- 安装清单可复制，也可下载为 `.md`。

**待确认**
- 按来源分组：AI 提案一组，每次扫描一组（显示扫描时间和环境）。
- 每张卡片显示：操作类型（新建、修改、弃用、合并）、目标条目、理由、内容（新建显示预览，修改显示逐字段差异）。
- 操作：接受、修改后接受（打开编辑页并载入草稿）、拒绝；支持多选后批量接受或拒绝。已过期（`superseded`）的提案单独标出。

**数据与设置**
- 外观：界面结构、配色、深浅色（跟随系统、浅色、深色），规则见 [08-ui-spec](08-ui-spec.md#切换与保存)。
- 数据：导出 JSON、导出 Markdown；导入时先选模式，并预览将导入和改名的数量，确认后执行。
- 字典：类型（名称、颜色、字段模板、排序）、平台、标签（改名与合并）。
- 整理规则：编辑 AI 整理档案时遵循的规则，默认内容见 [07](07-mcp-scanner.md#整理规则)。
- 关于：版本号、同步状态、上次同步时间。

**命令面板**：任意页面按 `Ctrl/⌘+K` 或 `/` 打开。结果分“条目”“环境”“操作”三组；方向键选择，回车打开，`Ctrl/⌘+Enter` 直接复制所选条目的第一个片段，`Esc` 关闭。没有结果时按回车，以输入内容为名称新建条目。输入结构或配色的名称（如“看板”“夜航”）时，“操作”组会出现对应的切换项。

**手机记录面板**：底部导航中间的“记录”按钮从底部弹出面板：类型标签（单选）、多行输入框、“写完整条目”“存入待整理”两个按钮。点遮罩或按 `Esc` 关闭，关闭后焦点回到触发按钮。

## 状态与离线同步

本地用 Dexie 保存一份完整副本：

| 表 | 内容 |
| --- | --- |
| `entries`、`stacks`、`types`、`platforms`、`proposals` | 与服务端实体同形；`entries` 以 `id` 为主键，并为 `type`、`status`、`updatedAt`、`tags` 建索引 |
| `outbox` | 待上传的写操作：自增序号、操作、实体 ID、请求体、`baseVersion`、`idempotencyKey`、创建时间、重试次数、最后错误 |
| `meta` | `cursor`（同步游标）、`lastSyncAt` |

流程：

1. 启动时先从 IndexedDB 读出数据立即渲染，再在后台拉取增量。
2. 拉取时机：启动、页面重新可见、恢复联网、页面可见期间每 5 分钟、每次上传成功之后。
3. 写操作先更新本地数据和 Dexie（乐观更新），再加入 `outbox` 并尝试上传。`outbox` 按顺序逐条上传：
   - 成功：用服务端返回的实体替换本地数据（拿到新版本号）。
   - 409：标记冲突，打开冲突对话框。
   - 422：撤销这次本地修改，在对应条目上显示错误。
   - 网络错误：留在 `outbox`，按 2 秒、5 秒、15 秒、60 秒退避重试，之后每 60 秒一次。
4. 多个标签页：用 Web Locks（`navigator.locks`）保证同一时间只有一个标签页执行同步；写入后用 BroadcastChannel 通知其他标签页从 Dexie 重新读取。
5. 同步状态显示在侧栏底部和设置页，四种：已同步、同步中、离线（显示待上传数量）、有冲突。

## 冲突处理

冲突对话框逐字段列出本地版本与服务器版本的不同之处，每个字段选择保留哪边，也可以整体放弃本地修改。确认后以服务器的最新版本号重新提交。

## 搜索

搜索函数放在 `packages/shared`，规则与原型一致：

- 按空白切分关键词，每个词都要命中。
- 权重：类型 ID 或类型名完全相同 10；名称或标识以关键词开头 12、包含 8；说明、标签、要点 4；片段和笔记 1；已弃用 -3；置顶 +1。
- 高亮按字符位置标记，不用用户输入拼正则。
- 条目超过 2,000 条时再换 MiniSearch，中文用 `Intl.Segmenter` 分词。

## 响应式与动效

| 宽度 | 布局 |
| --- | --- |
| ≤ 860px | 手机：单栏，底部导航，列表和详情分两屏 |
| 861–1100px | 紧凑：侧栏 + 340px 列表 + 详情 |
| > 1100px | 完整：侧栏 + 400px 列表 + 详情 |

页面切换用 View Transitions API，封装在 `lib/transitions.ts`；浏览器不支持或用户开启“减少动态效果”时直接切换。手机上按页面层级决定方向：进入更深一层从右滑入，返回从左滑入。桌面端切换条目只让详情栏做过渡。时长和曲线见 [08-ui-spec](08-ui-spec.md#动效)。

## 无障碍

- 所有可操作元素能用键盘到达，焦点清晰可见；对话框打开时锁定焦点，关闭后焦点回到触发元素。
- 当前导航项和选中行用 `aria-current` 标记；状态同时用形状和文字表达，不只靠颜色。
- 正文文字对比度达到 WCAG AA；手机上点按区域不小于 40px，输入框字号 16px（避免 iOS 聚焦时放大）。

## 文案

- 按钮写成具体动作，如“存入待整理”“生成安装清单”；同一个动作在按钮、提示、菜单里用同一个说法（按钮“存入待整理”，提示“已存入待整理”）。
- 错误信息说明发生了什么、怎么解决；空状态给出下一步可以做什么。
- 用词以 [术语表](../README.md#术语) 为准。

## PWA

- `manifest`：名称“AI 工作台”，`display: standalone`，图标 192/512，主题色取默认配色的背景色，运行时通过 `theme-color` 元标签跟随当前外观更新。
- Android 可声明 `share_target`：在别的应用里“分享到 AI 工作台”，打开记录面板并预填内容。iOS 用“快捷指令”调用 `POST /api/capture`（使用 `capture` 角色的服务令牌）。
- Service Worker 只预缓存前端静态资源；`/api` 和 `/mcp` 一律走网络，离线数据由 Dexie 提供。
- 检测到新版本时提示“有新版本，刷新后生效”，由用户决定何时刷新。
