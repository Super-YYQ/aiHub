# 08 界面规范

令牌的具体数值以原型 CSS 为准：基础布局与 B 配色在 `prototype/styles.css`，三套配色的差异和动效在 `prototype/themes.css`，五种结构在 `prototype/layouts.css`。本文件说明设计意图和规则，不重复抄写数值。

## 界面结构

结构决定页面怎么组织，和配色互相独立，可以任意组合。五种结构共用编辑、环境、设置等页面，差别在“工作台”和“条目”两类浏览页面。结构是全局设置，同时作用于这两类页面；正式版五种都实现，切换规则见[切换与保存](#切换与保存)。

| 结构 | 页面组织 | 适合 | 手机上 | 截图 |
| --- | --- | --- | --- | --- |
| 1 三栏 | 侧栏导航 + 列表 + 详情；在同一列表里切换条目时只更新详情 | 条目多，经常来回切换、对比 | 列表和详情分两屏 | [layout-1-panes.png](../ui/layout-1-panes.png) |
| 2 卡片墙 | 顶部类型标签，卡片按类型分组；卡片上能直接复制第一个片段；详情从右侧抽屉滑出 | 想一眼看全貌，按类型浏览 | 单列卡片，详情整页显示 | [layout-2-gallery.png](../ui/layout-2-gallery.png) |
| 3 搜索优先 | 页面中央一个大搜索框，左边结果、右边预览；方向键切换预览，回车复制 | 主要用法就是“搜到就复制”，习惯用键盘 | 搜索框加结果列表，点开后整页显示详情 | [layout-3-launcher.png](../ui/layout-3-launcher.png) |
| 4 看板 | 按状态分列，也可以按环境或类型分列；按状态分列时拖动卡片即可改状态；详情用抽屉 | 经常整理，把待整理逐步推进到在用 | 每列占一屏宽，左右滑动切换列；改状态在详情里做 | [layout-4-board.png](../ui/layout-4-board.png) |
| 5 知识库 | 左侧按类型的目录树，中间是文档阅读页，右侧是属性和本页目录 | 把配置当文档读，笔记较长 | 目录单独一页，文档页的属性放在顶部 | [layout-5-docs.png](../ui/layout-5-docs.png) |

| 结构 | 额外组件与交互 |
| --- | --- |
| 2 卡片墙 | `TypeTabs`、`EntryCard`（卡片内快捷复制；片段含变量时改为打开详情）、`DetailDrawer`（`Esc` 或点遮罩关闭） |
| 3 搜索优先 | `LauncherSearch`（进入页面自动聚焦）、`ResultList`、`PreviewPane`；方向键移动、`Enter` 复制、`Ctrl+Enter` 编辑、`Esc` 清空 |
| 4 看板 | `BoardColumn`、`BoardCard`、分组切换；桌面端拖放改状态，待整理列顶部可以直接记一笔 |

## 配色方案

| 配色 | 特点 | 适合 | 截图 |
| --- | --- | --- | --- |
| A 柔和 | 浮起的卡片、柔和阴影、大圆角（12–24px）、留白多 | 想要亲和、轻松的日常工具感 | [style-a-soft.png](../ui/style-a-soft.png) |
| B 沉静 | 细线分隔、信息密度高、圆角克制（4–16px） | 条目多、以查找和复制为主 | [style-b-calm.png](../ui/style-b-calm.png) |
| C 夜航 | 半透明磨砂面板，背后是按类型色调出的柔光；深色模式最出彩 | 喜欢有氛围感的界面，主要在深色下使用 | [style-c-glass.png](../ui/style-c-glass.png) |

在原型里切换：右下角（手机上在底部导航上方）的切换条有“结构”和“配色”两个下拉框，月亮按钮切换深浅色；也可以在“数据与设置”里切换，或在地址栏加 `?layout=panes|gallery|launcher|board|docs&style=soft|calm|glass&theme=light|dark`。

## 共同基础

- **类型色是唯一的彩色信息。** 8 种内置类型各有一种颜色（浅色和深色各一套），出现在侧栏色块、列表的类型色条或标记、路径前缀、类型标记上；其余界面保持中性色。
- **自定义类型的颜色**：用户从预设色里选（靛蓝、橄榄、棕、灰蓝，与内置色一样满足浅色背景上的对比度），深色模式下用 `color-mix(in srgb, <颜色> 60%, white)` 自动提亮。
- **状态用形状区分**：实心圆在用、半填试用中、空心想试、虚线待整理、划线已弃用，并始终带文字。
- **路径标识** `类型/标识` 用等宽字体，前缀按类型着色；它也是 Markdown 镜像的文件路径。
- **字体用系统字体栈**，不引用在线字体：中文依次 HarmonyOS Sans SC、MiSans、苹方、微软雅黑；代码依次更纱黑体、JetBrains Mono、Cascadia Mono、Consolas。
- **主按钮用墨色**（文字色作底），每个区域最多一个主按钮。
- **圆角按层级**：控件 < 面板 < 快速记录框和底部面板；具体数值由风格决定。

## 动效

| 场景 | 时长 | 做法 |
| --- | --- | --- |
| 悬停、按下 | 180ms | 背景、边框、阴影过渡；按下缩放到 0.98；A 风格卡片悬停上浮 1px |
| 详情切换（桌面） | 旧内容淡出 120ms，新内容 240ms | 只有详情栏参与过渡（`view-transition-name: detail`），列表不动 |
| 页面切换（手机） | 280ms | 进入更深一层：新页面从右侧 24% 处滑入，旧页面向左 10% 淡出；返回时方向相反 |
| 命令面板 | 200ms | 遮罩淡入，面板从上方 6px 处轻微放大淡入 |
| 底部记录面板 | 280ms | 从底部滑出，遮罩淡入 |
| 风格或深浅色切换 | 默认交叉淡化 | 整页 View Transition |

统一缓动曲线 `cubic-bezier(.2, .8, .2, 1)`。用户开启“减少动态效果”时，关闭全部动画和 View Transition。

## 手机交互

- 底部导航 5 项：工作台、条目、记录、搜索、环境；“记录”居中、最醒目，点击弹出底部记录面板（不跳页）。A、C 风格的底部导航是悬浮的圆角条。
- 顶部栏：进入二级页面时左侧出现返回按钮。
- 输入框字号 16px，点按区域不小于 40px，底部留出安全区（`env(safe-area-inset-bottom)`）。
- 列表筛选栏在滚动时吸顶。

## 切换与保存

五种结构和三套配色在正式版里全部实现，作为外观设置，随时可以切换。

| 事项 | 规则 |
| --- | --- |
| 入口 | 顶部栏的“外观”按钮打开外观面板，里面有结构、配色、深浅色三组选项（原型右下角的切换条就是它的样子）；“数据与设置 → 外观”也能改；在命令面板里输入结构或配色的名称（如“看板”“夜航”）可以直接切换 |
| 默认值 | 结构 1 三栏，配色 B 沉静，深浅色跟随系统 |
| 保存 | 按设备保存在浏览器本地，不同设备可以用不同外观（比如电脑用看板、手机用卡片墙）；不随数据同步，也不写进导出文件 |
| 首屏 | `index.html` 里的内联脚本在渲染前读取设置，写到 `<html>` 的 `data-layout`、`data-style`、`data-theme` 上，避免先显示默认外观再跳变 |
| 切换过程 | 整页 View Transition 交叉淡化；地址不变，同一个网址在任何结构下都打开同一个页面或条目 |
| 实现 | 三套配色的浅色、深色令牌都放进 `apps/web/src/styles/tokens.css`，按 `html[data-style][data-theme]` 生效；结构 2–5 的页面组件按需懒加载（动态 `import`），不增加首屏体积 |
| 测试 | 每种结构在桌面和手机视口都要跑功能用例；外观组合的检查见 [09-tasks](09-tasks.md#wp7awp7d-共同验收) |
